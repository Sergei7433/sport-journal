Как передать JSON

Между устройствами
📤 Основной способ — LocalSend

Работает без интернета, устройства видят друг друга по Wi-Fi.

  1. Оба устройства подключены к одной Wi-Fi сети (или один телефон раздаёт точку доступа).
  2. Установите LocalSend на оба устройства (бесплатно, Android и iPhone).
  3. На одном устройстве: «Отправить» → выбрать файл JSON → выбрать второе устройство.
  4. На втором: принять файл → открыть журнал → «Импорт JSON».
📤 Резерв — WhatsApp

Если Wi-Fi нет, но ловит мобильный интернет.

  1. Отправьте файл самому себе (в «Избранное» / «Заметки»).
  2. На втором устройстве скачайте из этого же чата.
  3. После использования — удалите файл из чата.
⚠️ Не пересылайте третьим лицам. ФИО детей — персональные данные.
📤 Если ничего не работает
  • Яндекс.Диск — загрузить → скачать на другом устройстве.
  • ВК — закрытый чат с самим собой, файл в сообщении.
  • USB-кабель — если рядом ноутбук, режим «Передача файлов».
⚠️ Персональные данные
  • Передавайте только себе или ассистенту.
  • Не выкладывайте в общие чаты и группы.
  • После использования удаляйте файлы из мессенджеров.
  • Печатные формы — «Для внутреннего использования».
